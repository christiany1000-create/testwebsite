Prerequisites

Before installing this mod, ensure you have the following ready:

  • Minecraft: (Update with your supported version, e.g., 1.20.1)
  • Mod Loader: Fabric or Forge (Update based on what your mod uses)
  • Dependencies: Fabric API (if using Fabric) or any other required library mods.

Step-by-Step Instructions

  1. Install the Mod Loader
    Download and run the installer for your chosen mod loader. Ensure you select the "Client" installation option.
  2. Download the Mod
    Download the .jar file for our mod from the home page or directly from Modrinth.
  3. Locate your Minecraft Folder
    Find your .minecraft directory based on your operating system: Windows: %appdata%\.minecraft
    Mac: ~/Library/Application Support/minecraft
    Linux: ~/.minecraft
  4. Place the Mod
    Open the mods folder inside your Minecraft directory. (If it doesn't exist yet, simply create a new folder and name it mods). Drag and drop the downloaded .jar file into this folder.
  5. Launch the Game
    Open the Minecraft Launcher, click the drop-down menu next to the "Play" button, select your new Mod Loader profile, and start the game!

Troubleshooting

If the game crashes on startup, double-check that you have downloaded the correct version of the mod that matches your Minecraft version. Also, verify that all required dependencies are installed correctly in your mods folder.
